# Taller de testing exploratorio: TiendaQA

Actividad práctica para Fundamentos de Ingeniería de Software. **TiendaQA** es una tienda online de práctica con errores puestos a propósito. Cada grupo hace una sesión de testing exploratorio sobre una parte de la tienda y completa el reporte de sesión con la plantilla vista en clase.

> Los errores son intencionales

## Requisitos


## Ejecutarlo en tu computadora

```bash
npm install
npm run dev
```

Se abre el navegador en `http://localhost:5173/`. Si no se abre solo, entrá a esa dirección. Para cortarlo: `Ctrl + C` en la terminal.
